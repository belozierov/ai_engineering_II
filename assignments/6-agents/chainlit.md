# Ops Copilot v2

Локальний навчальний інтерфейс для синтетичних incident-сценаріїв.

- Запускайте лише на localhost.
- Не вводьте production-дані, PII, credentials або API keys у чат.
- Сесії не автентифіковані, тимчасові та ізольовані.
- Chainlit UI не входить в автоматичне оцінювання.

Інструкції та ручні сценарії: `README.md` і `TESTING_SCENARIOS.md`.
